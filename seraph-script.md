# Software Requirement Specification for Seraph

## Project Vision
Seraph is to be a comprehensive nutrition and training record keeper.

## KPIs
- Clear visibility of food consumption  history
- Ease of entry for new food information
- Ease of entry for new training information
- Clear visibility of training history

## Architecture
### Software Architecture
#### Features
- Authentication and Authorization
- Food Database
- Meal Planner
- Nutrition Log
- Nutrisight
- Backup and Restore
- Trainsight
- Training Log
- Training Planner
- Training Database

#### Technologies
- Compose Multiplatform for Android and Desktop
- SQLite3 Database

### Structure
- Mobile Client
- Presentation Layer
- Data Processing Layer
- Two in-app atabases
